# G14 搜索、导航与目录契约

日期：2026-10-21。基线提交：`af51fe7`；结果来自本次工作区改动。

## 目录决策（T044）

保留 SQLite `INTEGER sort_key` 和 `ORDER BY sort_key,id`。普通移动以 `(parent_id,sort_key,id)` 索引读取前后邻居，只更新移动节点；间隙不足时在同一业务事务中重排同级并记录变更，复用预编译 UPDATE。不为设计文本中的字符串排序建议进行格式迁移。

`listNodes` 保持完整目录元信息快照（含软删除节点，不载入正文），前端以显式栈生成可见树并虚拟渲染。当前不引入分页子项 API，否则收藏、标签、移动候选、祖先展开与客户端快照语义都需一起调整。分页不列为当前已实现能力。深层目录缩略章节编号、保留层数与标题，完整标题由现有提示和无障碍名称提供。

## 搜索与修复（T042）

- `SearchResult.location` 是可选判别联合：`text` 携带查询词，`pdf` 携带页码或批注锚点，`metadata` 表示没有可定位的正文命中。空查询只预览与打开。
- 只对最终限量结果解析定位，按 Notebook 分组复用连接；不对所有候选结果加载正文。定位取自当前正文、与现有资源哈希相符的 PDF 索引或未删除批注，不使用 FTS 拼接文本的偏移。
- 正文打开后选中首个可见文本命中并滚动；PDF 页面跳至首个命中页，批注跳至该页并描边对应矩形与批注卡片。标题/标签命中打开属性面板。FTS 中仍可搜索到的旧资源批注不会被当作当前资源的位置。
- 快速打开提供跟随键盘/鼠标选择的纯文字预览，异步请求有延迟与失效保护。预览不写入导航历史。
- 在编辑器中按 Ctrl/Command 点击内部链接。目标不存在、在回收站或所属库未登记时，打开修复搜索入口。选择替代笔记后，先保存草稿，再验证源/目标和源修订号，替换完整目标地址，保留链接标签；正常保存流程更新历史与反链。取消不会修改正文。

## 导航与 Notebook（T043）

- 前进/后退记录 Notebook、笔记、搜索位置和 PDF 锚点，最多 100 次；从旧位置打开新目标清除前进分支。跨库跳转不再额外打开目标库首篇笔记。
- 文档标签最多 20 个；可隐藏并持久化偏好；支持切换、关闭和左右/Home/End 键移动焦点。关闭当前标签会打开相邻标签。标签隐藏不关闭文档。
- 属性面板展示标题、类型、创建/修改时间、标签、字数、来源和 Notebook 路径；窄窗口作为可关闭覆盖面板。
- Notebook 创建和重命名支持图标、封面色。创建位置为空时用默认知识库目录；指定已有绝对路径时，在其下新建 UUID 子目录并登记，不覆盖已有文件。
- `notebook_meta` 增加 `icon`、`cover_color`，随数据库、归档和备份携带；修改经过业务事务与备份修订触发器。**这是开发期 v4 schema 的扩充，遵循项目不兼容历史格式的约定；不提供旧版数据库迁移。** 严格 schema 校验会拒绝未包含新字段的旧格式库。
- `listNotebooks` 返回本机实际路径；路径与最近打开时间不写入可移植数据库。最近 5 本显示路径、最后打开时间和明确标注的本地快照状态，云端/磁盘备份仍以备份页为准，不把“本地已保存”当作备份成功。
- 新偏好键为 `anynote.navigation.tabs`、`anynote.notebooks.visits`。书橱进入工作区流程及简洁顶部保留。
