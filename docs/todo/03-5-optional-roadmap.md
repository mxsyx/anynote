# 可选能力路线图

[返回功能任务入口](03-feature-logic.md) · [返回总入口](../../TODO.md)

更新：2026-10-25。

本文件集中维护 15 条 P3 可选能力，不作为一个实现会话。先确认范围和契约，再按下表独立立项；涉及多种独立能力的任务继续拆成多个会话。评估或设计完成不能替代功能完成。

## 会话与依赖

| 任务 | 建议会话边界                                                                     | 前置与并行限制                                                  |
| ---- | -------------------------------------------------------------------------------- | --------------------------------------------------------------- |
| F009 | 源身份/分叉契约 → 跨会话优化与性能回归                                           | 保留既有基线；与修改捕获或格式的任务错开                        |
| F010 | 负载分析与格式设计 → checkpoint/delta 实现及恢复测量                             | A007–A009 负载数据；与备份格式、远端维护改造串行                |
| F012 | 草稿协议 → 崩溃恢复实现与冲突/导出回归                                           | 与编辑器保存、导航和视觉改造错开                                |
| F013 | 模型/上下文契约 → Provider 流式调用 → 面板与提案交互                             | 先与 F014 对齐授权和提案契约；共享契约修改串行                  |
| F014 | 授权与操作契约 → 按工具族实现 → 批量事务/补偿和安全回归                          | 与 F013 分别实施；不得让模型输入扩大宿主权限                    |
| F015 | MCP token/会话适配及审计                                                         | F014 知识工具与授权契约稳定、确认采用 MCP 后启动                |
| F016 | 每种语法的持久化/降级 → 编辑/导出；复杂能力分别定范围                            | 仅合并共享编辑/导出文件及测试的语法；与 F012 错开保存协议修改   |
| F017 | 模型与索引预算 → OCR → 语义索引                                                  | 先定可重建索引契约；共享索引和查询接口变更串行                  |
| F018 | 带批注 PDF 输出及坐标/字体/渲染验收                                              | F007 确认需求；完整 PDF 编辑和原件写回另定范围                  |
| F019 | 隔离浏览/登录态授权 → DOM 获取和清洗接入                                         | 需用户选择登录态；与 F020 共享宿主授权改造时串行                |
| F020 | 模块执行、React 隔离视图、高权限原生等级、私有分发认证、热更新、市场运营分别立项 | 各自明确沙箱/授权和测试；共享宿主契约先定，静默安装另定授权策略 |
| F021 | 威胁模型与密钥恢复/轮换设计 → 按备份/恢复/AI 影响分阶段实现                      | 先确认加密范围；与 F009/F010 的格式改造协调顺序                 |
| F022 | 身份/冲突协议 → 同步、移动端、协作分别立项                                       | 后续依赖共同协议，不合为一个跨端实现会话                        |
| F023 | 托管范围 → 租户/设备认证 → 计费和容量方案分别实施                                | 确认托管模式后启动；认证契约稳定后再安排独立工作                |
| F024 | 消费需求与现有脚本盘点 → 按需实现 CLI 或拆仓                                     | 复用现有工具；与 F006 修改构建、打包和发布入口时串行            |

上述并行限制是任务范围层面的预案。可选项启动时仍须核对实际文件、测试和规模；只有无共享写入且无依赖的会话才并行。不能只因同属 AI、编辑器或备份就合并。

## 任务

<a id="f009"></a>

### F009 · 跨会话免捕获优化

- [ ] **P3 — 跨会话免捕获优化**：在能可靠识别源替换/分叉后，评估重启或 LRU 淘汰后的首次任务跳过捕获；补齐重启、淘汰、替换和分叉回归。当前保守捕获行为正确；新增表或格式必须更新版本契约。

本地大清单基线已完成，可在既有基线上评估；源替换/分叉识别与格式契约仍须先明确。

<a id="f010"></a>

### F010 · Cloudflare checkpoint 策略优化

- [ ] **P3 — Cloudflare checkpoint 策略优化**：评估从每代完整实体映射改为周期 checkpoint+delta，以及可选 SQLite 恢复加速点；测量链长、上传量和恢复成本，完整定义依赖保护。当前每代自包含 checkpoint 可正确恢复，不属于可靠性缺陷。

启动条件与拆分边界：先取得 [A007](02-3-cloudflare.md#a007)–[A009](02-3-cloudflare.md#a009) 的负载数据；基于现有维护生命周期协议另行确定 delta 依赖保护，单独开展格式设计。

<a id="f012"></a>

### F012 · 崩溃草稿日志

- [ ] **P3 — 崩溃草稿日志**：评估防抖窗口内的设备侧草稿恢复，覆盖 Renderer/存储进程崩溃、重启、冲突和导出；现有保存失败保留内存草稿不等于未提交输入可跨进程恢复。

启动条件与拆分边界：单独处理编辑器保存与设备草稿协议；与导航、视觉改造错开。

<a id="f013"></a>

### F013 · AI Provider 与面板

- [ ] **P3 — AI Provider 与面板**：接入可选本地/远端模型、流式输出、设置和用量；实现授权 Context Builder、引用、可读 diff、批量接受/拒绝/撤销与审计。现有单笔记 propose/apply/undo 接口已实现，未配置或调用模型。

启动条件与拆分边界：先明确模型和授权上下文；与 [F014](03-5-optional-roadmap.md#f014) 对齐提案契约，分别实施模型面板与工具事务。

<a id="f014"></a>

### F014 · AI 工具与批量事务

- [ ] **P3 — AI 工具与批量事务**：补齐范围内树/搜索/创建、移动、标签、链接、导入和回收站工具，稳定块 ID/范围定位、operation ID、过期提案拒绝及跨库补偿；验证网页/PDF 提示注入不能改变宿主授权或触发外发/删除。

启动条件与拆分边界：先稳定授权范围和操作契约；批量事务、补偿及提示注入回归独立验收。

<a id="f015"></a>

### F015 · 可选 MCP 适配

- [ ] **P3 — 可选 MCP 适配**：复用知识工具 API，加入 token/会话授权、Notebook 范围和审计；不默认开放无鉴权本地端口。

启动条件与拆分边界：依赖 [F014](03-5-optional-roadmap.md#f014) 的知识工具和授权契约；确认采用 MCP 后再安排适配。

<a id="f016"></a>

### F016 · 编辑器下一批扩展

- [ ] **P3 — 编辑器下一批扩展**：Callout、折叠、数学公式的成熟协议与首方编辑/导出；后续复杂表格、多列布局、评论、更多笔记类型及知识图谱须先定义持久化和无插件降级。已有声明式 callout/details 能力可复用。

启动条件与拆分边界：每种语法先定义持久化与无插件降级，再按共享编辑/导出代码分批。

<a id="f017"></a>

### F017 · OCR 与语义检索

- [ ] **P3 — OCR 与语义检索**：通过 SearchProvider 生成可重建索引，记录模型版本、内容哈希、分块和标脏策略，覆盖扫描 PDF/图片；不替换原资源。

启动条件与拆分边界：先明确模型、索引预算和可重建策略，再实现 OCR/语义索引。

<a id="f018"></a>

### F018 · PDF 批注文件导出

- [ ] **P3 — PDF 批注文件导出**：如支持带批注 PDF，输出新文件并核验坐标、字体与渲染；完整 PDF 编辑/原件写回单独定范围。

启动条件与拆分边界：[F007](03-4-release-scope.md#f007) 确认需求后单独做 PDF 文件输出及坐标/字体验收。

<a id="f019"></a>

### F019 · 动态网页导入

- [ ] **P3 — 动态网页导入**：受信插件的隔离浏览会话和用户选择的登录态，获取 DOM 后继续清洗；不自动绕过登录/付费墙。

启动条件与拆分边界：先确定隔离浏览会话与登录态授权，复用已实现的流式媒体导入和资源授权边界。

<a id="f020"></a>

### F020 · 扩展生态扩大

- [ ] **P3 — 扩展生态扩大**：通用第三方模块/React 隔离视图、可选高权限原生等级、私有分发认证、热更新与市场审核运营；逐项定义沙箱/授权，不能把 utility process 本身当权限沙箱。静默自动安装需独立授权策略。

启动条件与拆分边界：模块执行、隔离视图、分发认证和市场运营分开立项，不作为一个实现会话。

<a id="f021"></a>

### F021 · E2EE

- [ ] **P3 — E2EE**：定义密钥恢复/轮换、设备授权、加密 manifest、对象命名泄露、历史与 AI 明文访问；普通 TLS、系统凭据加密及 D1/R2 私有对象不能标为端到端加密。

启动条件与拆分边界：先做密钥恢复和威胁模型设计，再评估对备份/恢复/AI 的影响。

<a id="f022"></a>

### F022 · 多设备同步、移动与协作

- [ ] **P3 — 多设备同步、移动与协作**：另行定义冲突/合并和身份协议；现有单写 epoch、显式分支和恢复副本不等于实时同步。

启动条件与拆分边界：同步、移动端、协作分别明确产品范围；先定义身份与冲突协议。

<a id="f023"></a>

### F023 · 商业托管与容量扩展

- [ ] **P3 — 商业托管与容量扩展**：如采用托管版，设计账号/租户/设备认证、计费及 D1 分片/bindings；现有个人 APP_TOKEN 不是多用户认证体系。

启动条件与拆分边界：只有确认托管模式后才启动租户、计费和容量方案。

<a id="f024"></a>

### F024 · 独立 CLI 与仓库拆分

- [ ] **P3 — 独立 CLI 与仓库拆分**：按实际需要整理导入、导出、修复、部署 CLI，以及 SDK/插件/部署模板独立仓库；已有脚本/开发工具先复用。

启动条件与拆分边界：先盘点现有脚本和公共包；依据真实消费需求拆 CLI 或仓库。

## 启动与完成条件

- 每次只选择范围已确认的一项或一个明确阶段，记录所需上下文、实际文件/测试、输入契约、完成条件和剩余阶段。新表或新格式必须同步版本契约。
- 模型/凭据尚未就绪时可先完成本地接口和测试；远端调用、真实登录态及设备验收分别记录，不把模拟结果记成真实通过。
- F014 的工具和授权契约解锁 F015；F013 只需先对齐共享契约，不必等待 F014 所有工具完成。F010 需 A007–A009 的负载证据，不能仅凭历史恢复结果启动格式优化。
- 性能优化保留前后数据；新能力的实现、运行时校验、相关回归和文档全部完成后才能结项。

完成与交接遵循[统一规则](03-feature-logic.md#handoff)。阶段完成不等于整项完成；未满足完整验收条件时保留未勾选。
