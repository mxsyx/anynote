需要提供测试账号的授权、OAuth 应用身份、Token、签名证书，或受控服务的管理权限。通常通过系统登录、OAuth 或环境配置提供访问能力；任务文档不保存账号密码和密钥。插件公网端点归本类是因为需要可控外部服务，不表示客户端必须输入密码。

### A001 · 官方 OAuth 应用注册与真实授权

- [ ] **P0 — 官方 OAuth 应用注册与真实授权**：为 Google Drive、Dropbox、OneDrive 准备开发/生产应用身份，配置授权页、隐私政策、回调及必要审核。在真实桌面验证系统浏览器唤起、回环回调、state/PKCE、超时与端口占用、撤销和重新授权。身份注入、错误提示和本地回归已有实现，本条仅保留厂商注册/审核及真实授权验收。步骤见 [OAuth 注册](../OAUTH-REGISTRATION.md)。

<a id="a002"></a>

### A002 · Google Drive 真实端到端验收

- [ ] **P0 — Google Drive 真实端到端验收**：以真实账号验证 `drive.file` 最小权限下的目录创建/发现/上传/下载/删除、resumable 上传（256KiB 分片、服务端确认偏移、会话失效重建）、上传后下载校验、配额与 403 reason 分类、`current` 读回确认。当前 `googleapis` 调用路径与上传下载协议未经过真实 API 验证。

同批补齐 Dropbox App Folder 与 OneDrive AppFolder 最小权限下的真实创建、列表、上传、下载、删除及分段上传闭环；三个 Provider 的实现均已有记录，不重复开发。

<a id="a007"></a>

### A007 · 真实远端故障与长期调度

- [ ] **P0 — 真实远端故障与长期调度**：覆盖网络中断/限流、鉴权或权限撤销、配额不足、服务不可用及多轮自动备份；核对退避、取消、幂等、提交结果确认、旧版本可恢复和本地编辑不受阻，保留真实服务报告。

续传协议还需在真实服务验证：上传/下载中断与 Storage 重启后的实际字节复用、未登记的空 multipart、默认/自定义桶生命周期、服务端复制中断、abort 丢响应，以及短于 7 天桶规则下的会话重建。参见 [续传协议](../adr/014-cloudflare-transfer-resume.md)。

<a id="a008"></a>

### A008 · 真实老化对象回收

- [ ] **P0 — 真实老化对象回收**：Cloudflare R2 实测超过 24 小时宽限期的无引用对象删除，同时验证保留版本、其他分支、staging 和恢复保护不受损。当前 aged-object 删除主要依赖受控时间合约。

当前维护协议复测还需覆盖：超过 24h 的孤立 manifest/临时对象、连续 7 天无活动 staging、归档写失败后的恢复及墓碑旧 ID 重放；保护保留版本、分支和恢复任务。参见 [维护生命周期协议](../adr/013-remote-maintenance-lifecycle.md)。

### A009 · 远端容量与真实负载

- [ ] **P2 — 远端容量与真实负载**：测量大规模维护规划、20GiB/大量附件、长期版本积累、D1/R2 配额与成本；必要时拆分清单、分批验证或异步任务。现有重复块 112MiB 样本不代表随机数据吞吐或满预算通过。

补测 2000 活动版本、200000 引用、满上传会话预算、随机大文件吞吐、永久归档增长及首次预览请求量；记录 D1/R2 实际成本。空间估算不包含 D1、维护归档和未完成 multipart 分段。
