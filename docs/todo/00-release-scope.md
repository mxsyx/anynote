# G00 · 首发范围与发布证据

[返回总入口](../../TODO.md)

类型：产品决策 / 验收统筹。目标：确认首发边界，建立并最终汇总发布证据表。

前置：先形成首发范围决策；最终结项依赖范围内所有发布门槛的报告。

并行边界：证据表可立即建立；各实现组不必等待所有产品问题解决。

## 建议入口

- [docs/Anynote-Design.md](../../docs/Anynote-Design.md)
- [docs/P0-BACKUP-READINESS.md](../../docs/P0-BACKUP-READINESS.md)
- [docs/RELEASE-MATRIX.md](../../docs/RELEASE-MATRIX.md)

## 执行顺序

1. 开场会话确认平台/架构、数据规模及首发能力，建立逐项证据表。
2. 按 AGENTS.md 重审旧清单中的历史兼容要求：开发期不新增历史数据兼容层，也不为已移除功能补测试；需要的版本拒绝边界另行记录。
3. 验收期间只接收各组证据，最后单开收尾会话汇总；未执行、受阻与失败分别标注。

## 验证与完成条件

- 核对发布范围、每项证据链接、版本、设备、语料及未执行原因。

完成条件：T070 的范围决策和 T004 的发布证据分别结项；建表不代表发布门槛已通过。

人工 / 外部资源：产品负责人确认范围和发布日期；需要本人账号、证书或设备的环节由对应验收组安排。
