# G03 · 独立设备与物理磁盘演练

[返回总入口](../../TODO.md)

类型：验收 / 实测。目标：独立恢复、外接盘/磁盘满、断电、设备性能组合。

前置：独立测试设备、测试数据、备份副本和外接磁盘；Windows 项依赖 G04，云盘恢复可复用 G01。

并行边界：与代码实现并行；同一设备的恢复、拔盘、断电和性能采样按顺序执行。

## 执行顺序

1. 准备便携验收包和独立测试资料，先证明副本能在干净设备恢复。
2. 在测试数据上分批覆盖 exFAT、USB 重连、挂载点换卷和磁盘满。
3. 再执行发布/清理阶段断电及整机不可用演练，记录切点和旧副本保护结果。
4. 用同批设备记录双分区/独立磁盘与冷热缓存性能；G04 的设备提示实现后补测相应提示。

## 验证与完成条件

- `pnpm run test:recovery:portable verify`
- `pnpm run test:desktop:local-backup`
- `pnpm run benchmark:local-backup`

人工 / 外部资源：准备独立设备/外接盘，执行物理插拔与断电，确认测试数据隔离。
