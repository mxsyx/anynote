- 资源：可控公网 HTTPS 服务、域名/证书，以及可配置 DNS/地址异常、延迟、撤销和超预算响应的环境。需要服务管理权限，不表示客户端必须输入密码。

- 先按现有扩展宿主协议准备端点场景，再执行真实桌面访问并记录拒绝原因和资源预算；本地 fixture 通过不替代公网结果。
