# 浏览器笔记采集

Chrome/Edge Manifest V3 扩展，入口为网页选区右键菜单与 ChatGPT 对话页按钮。界面采用白色背景与扁平化控件，使用统一的笔记 A Logo 与带文字的 Lucide 按钮图标，蓝色突出主要操作，支持窄侧栏与键盘焦点。当前提供可加载的开发版本；真实 ChatGPT 接口和真实云端验收状态见 [F025](../development/TODO.md#f025)。

## 安装与采集

1. 执行 `pnpm run build:browser`。
2. 在浏览器扩展管理页启用开发者模式，加载 `apps/browser-extension/dist`。
3. 选中网页内容，右键选择“采集到 AnyNote”。在侧栏核对标题、Markdown 和媒体。
4. 扩展启用后默认在 ChatGPT 对话页注入“采集对话”按钮，无需手动开启。安装/更新时授予 `chatgpt.com` 访问权限；若浏览器暂停了扩展，确认权限后重新启用。打开已保存对话后点击“采集对话”。
5. 点击“下载媒体”并授权相应站点，然后复制 Markdown、导出 `.anyclip` 或导入云端。无法下载的媒体或未转换的特殊内容必须勾选“允许保留未下载媒体的缺失说明”才能导出；未勾选时会聚焦该复选框，并在导出按钮下提示原因。切换采集记录后需重新确认。

选区转换保留标题、列表、引用、代码与表格，媒体先保存在扩展 IndexedDB。普通复制不携带二进制文件；本地媒体和带签名参数的链接变成说明文字。`.anyclip` 是带版本、SHA-256 清单、Markdown 和媒体的 ZIP 采集包，不是完整 Notebook `.anynote` 备份。桌面通过“导入网页 → 采集包 .anyclip”选择文件并确认导入。同一采集 ID 和内容重复导入不会新增笔记。

侧栏“删除记录”会同时清理不再被其他记录引用的本地媒体。草稿可以在关闭侧栏后恢复，但临时下载地址不持久化；未下载资源需要重新采集来源页面。媒体单文件最多 20 MiB、合计 80 MiB、最多 200 项。正文最多 2,000,000 个 JavaScript 字符及 8 MiB UTF-8；ZIP 最多 90 MiB、202 个条目。超限拒绝，不静默截断。图片另按共享像素预算检查。

## ChatGPT 图片组与卡片

`AsyncImageGroup` 按消息标识关联网页上已渲染的图片组，提取原图地址并转换为 Markdown 图片；不会用 `query` 搜索词重新找图。采集前请在原对话加载图片，采集后点击“下载媒体”并授权图片站点，成功下载的文件会进入 `.anyclip`。网页未渲染图片、组数无法对应或地址不支持时会保留缺失说明；仅获取链接不算离线保存。虚拟列表或轮播未呈现的内容仍需回到原页加载后重采。

`box`、`row`、`column`、`caption`、常用 `icon` 及以 `div` 为根的基础 HTML 卡片会转换为带内联样式的 HTML，保留支持的背景、边框、圆角、间距、对齐、粗体、说明文字与箭头。代码块、行内代码和用户消息中的示例保持原样。仅保留受限标签和样式，不执行 JSX 表达式、脚本或事件处理器；任意网页组件不保证完整还原。卡片内的图片组置于卡片下方，其他内嵌媒体暂时显式报告缺失。

桌面阅读器支持显示经过重新校验的采集卡片，需使用本次构建的桌面版本；普通未标记 HTML 仍按原有方式显示。复制 Markdown 会保留卡片 HTML，最终外观取决于目标应用是否允许内联 HTML 和样式。更新扩展不会改写已保存的采集记录，需要重新采集。

## Cloudflare 配对与归入

服务端必须运行本版本 Worker、应用全部 D1 迁移至 `0007.sql`，并支持 `capture-v1`、`browse-snapshot-v1`。当前 Notebook 为 schema v5，不兼容开发期旧 schema。

若生成配对码提示“接口不存在”，通常是仍连接未提供采集接口的旧 Worker。新版桌面会先检查 `capture-v1`，缺少时明确提示升级 Worker 和迁移 0007。只修改 Token 或重新生成桌面配置不能补齐接口。已有旧 schema 备份的服务应先评估恢复兼容性；可为新版本单独部署 Worker、D1 和 R2，保留原服务处理旧备份。

点击侧栏右上角齿轮“设置”，进入独立设置视图；Cloudflare 配对、目录、阅读与采集箱均在此页。点击“返回采集”可回到原草稿，当前选择的云端导入目录也会保留。未登录时点击“导入云端”会引导到设置页。浏览器扩展的“选项”也可直接打开设置。

桌面端先打开一本 Notebook，再从顶部菜单“应用 → 备份与恢复…”进入备份页（macOS 为“Anynote → 备份与恢复…”）。向下找到“远端备份”，在 Cloudflare 目标卡片点击“采集设备 → 生成一次性配对码”。尚未配置目标时，先点击“添加目标”并完成一次备份；“设置 → 从云端恢复”用于恢复已有备份，不生成配对码。将 Worker HTTPS 根地址和配对码输入扩展。配对码有效 5 分钟；设备授权有效 30 天，限制到指定 notebook/lineage，仅保存在浏览器当前会话内。APP_TOKEN 不进入扩展或网页。桌面可以查看及撤销设备。

扩展按需展开目录树、查看 Markdown 原文、下载附件及预览 PNG/JPEG/WebP 图片。单次附件查看预算 20 MiB，更大附件需在桌面查看。目录是最近已提交云备份的视图，显示备份时间；不包含回收站与历史修订。未生成浏览投影的备份会提示不可浏览，不伪装为空笔记本。

选择根目录或某个文件夹后“导入云端”，内容立即进入可读采集箱。桌面“立即备份”或已启用的自动备份会领取采集、写入本地，再发布备份：

| 状态             | 含义                                     |
| ---------------- | ---------------------------------------- |
| 上传中           | 可重试同一冻结采集，尚未完整提交         |
| 待桌面归入       | 云端已有完整内容，桌面尚未写入           |
| 已归入，等待备份 | 本地事务和防重复回执已持久化             |
| 已备份           | 同一 SQLite 快照包含回执，云端提交已确认 |
| 需要重新选择目录 | 目标目录已失效，在采集箱选择新目标后重试 |

云端不会在桌面离线时改写正式 Notebook。每笔记本最多 100 项未清理采集副本，每轮备份最多归入/确认 20 项。采集对象保留在独立存储前缀，不随备份 GC 删除；已备份项可显式清理正文与媒体副本，保留回执并转到正式笔记。清理中断可以重试；待归入或未备份内容不能清理。

## 当前边界

ChatGPT 使用实验性内部网页接口适配。会话凭据只在网页 MAIN world 内使用；输出仅含公开 user/assistant 消息，沿当前分支父链排序，不保存原始响应或凭据。空文本、已知思考/摘要节点与发往工具的消息不进入正文；其余非文字消息部分记录为缺失，并附带有界格式标识供问题定位；不保存原始特殊内容或凭据。旧采集记录不会因更新扩展而重新解析，需要回到来源页重新采集。无法解析为来源链接的 Cite 引用显示“引用来源见原对话”，代码中的示例标记保持原样。真实会话已确认文字、表格和代码块可获取，用户更新后确认采集及 `.anyclip` 导出正常；ChatGPT 专有附件解析、生成图片、引用 URL 与分支切换尚未通过真实会话验收。接口结构变化、无法确认分支或历史缺失时会报错。

当前 schema v5/迁移 0007 的真实 Cloudflare 部署已通过配对、浏览、含图片与卡片的采集上传、桌面后端归入、防重复和撤销协议验证；桌面 GUI 与扩展侧栏的真实云交互仍需单独核对。目前没有商店发行包。浏览器内最大包的内存峰值、PDF 内嵌阅读、未提交云上传的取消与 TTL 回收仍未完成验收/实现，详见唯一待办 [F025](../development/TODO.md#f025)。
