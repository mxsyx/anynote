# 工作区设置与管理页面

通过桌面应用菜单进入设置、插件与扩展、备份与恢复。三页采用统一的原生工具面板：页头标明作用范围，分组标题和说明在上，相关操作放在同一组内。窄窗口下操作自动换行，明暗主题使用同一套布局。

- **设置**：外观、Notebook 管理、数据迁移、云端恢复、诊断。明亮与深色选项立即生效，沿用设备的外观偏好保存，与工具栏及原生菜单的主题切换同步。
- **插件与扩展**：先展示内置扩展及其独立开关，再展示首方宿主、更新、目录与安装、发布者、已安装扩展和数据清理。内置扩展的权限及底部开发者说明可展开；安装审核中的来源与权限仍直接显示。
- **备份与恢复**：先展示本地快照和归档导入导出，其后依次为本地磁盘备份、远端备份、本地存储整理。宽窗口并排显示快照与归档，窄窗口改为纵向排列。远端目标卡片将名称与立即备份放在顶部，备份状态、凭据保护和服务地址分别展示；自动备份单列为开关行，辅助操作放在底部。设备暂停策略按电池供电、计量网络分别呈现独立开关。

原生菜单包含应用（macOS 为 Anynote）、编辑、显示、帮助。应用和编辑菜单使用中文标签，保留原生编辑快捷键；显示菜单提供主题切换，帮助菜单提供“关于 Anynote”。

布局共用 `ManagementPage` 和限定在 `.management-page` 内的 `management.css`，复用现有按钮、输入框及主题变量。备份与扩展权限、恢复流程、数据保存方式不变；弹窗依然只在用户打开时创建。

本地界面回归命令：`pnpm run test:management`。它使用隔离的 Electron 用户目录检查两种主题、1440/900 宽度的页面布局、主题保存、扩展开关、快照创建与备份弹窗；截图保存于 `tmp/screenshots/management/`。已配置远端卡片的截图使用无凭据、自动备份关闭的隔离数据，覆盖长服务地址、失败提示和暂停策略开关。该检查不代表真实远端备份或物理磁盘验收。
