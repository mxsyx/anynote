# 工作区设置与管理

Rust 工作区提供书橱、目录、搜索、阅读、历史和设置入口；任务、诊断、本地/云备份、恢复与采集管理通过原生管理窗口访问。具体入口与服务约束见 [工作区契约](../development/RUST-WORKSPACE.md)、[管理契约](../development/RUST-MANAGEMENT.md)。

外观偏好在设备侧保存；Notebook 名称、图标、封面等知识库数据随数据库与备份携带。媒体和阅读业务使用静态偏好，不提供插件安装、授权或更新页面。

备份状态、连接凭据、暂停策略和任务进度分别呈现；恢复、删除与云 writer 接管须按对应业务确认。动态对话框按需创建，关闭后恢复焦点。

原生菜单、键盘、读屏、窄窗口、主题与跨屏 DPI 的实际验收见 [平台任务](../development/TODO.md#platform-validation)。
