# 签名扩展的远程分发与手动更新

扩展页支持输入公开 HTTPS 签名包地址，点击“下载并审核扩展”，核对来源、公钥指纹、版本、贡献和权限，再信任发布者并确认安装。只接受现有声明式或受限 QuickJS 转换扩展的 [Ed25519 签名包](EXTENSION-SIGNING.md)。本地未签名开发 JSON 的安装方式保持可用；远程入口不接受未签名定义。

## 分发者

使用 `pnpm run extension:package sign ...` 制作 `.signed.json`，将该文件放在自己的公开 HTTPS 静态托管地址，通过独立渠道提供公钥指纹。无需上传私钥。更新时使用同一把私钥，以更高的 `0.1.N` 版本签名新包，并替换相同地址的文件。下载链接或 HTTPS 证书本身不替代发布者签名与指纹核对。

不需要中央市场或服务器端索引。默认由用户触发下载与检查；用户可在设备上开启 [自动检查更新](EXTENSION-UPDATE-CHECKS.md)，安装仍需人工审核。远端能看到请求地址、时间和网络 IP。下载请求不携带 Notebook 内容、Cookie、云凭据、系统密钥或发布者私钥。

## 安装与更新

下载和签名校验不改变现有安装、Notebook 授权或内容。审核展示请求地址；发生重定向时同时展示最终地址。安装使用后端保存的同一份审核快照，不在确认时再次下载，避免审核后远端文件变化导致安装不同内容。

远程安装保存初始 HTTPS 地址作为设备侧更新来源。已安装卡片提供“检查扩展更新”：

- 相同 manifest 内容返回“已是最新版本”，保持现有授权。
- 新版展示安装审核；审核前后知识内容保持原样。确认安装后须为各 Notebook 重新授权。
- 不同扩展 ID、不同签名密钥、低版本或同版本不同内容均被拒绝。
- 确认安装时重新验证发布者信任和已安装扩展内容校验。审核期间被替换或卸载的安装不能被过期审核覆盖。

撤销发布者信任的规则继续生效。取消下载会终止在途下载并清空本设备会话的下载审核；知识库服务关闭同样取消下载。审核快照最多保留 8 份、每份有效 10 分钟，超限淘汰最旧快照。成功安装后快照消费一次；重新打开应用需要重新下载。持久的更新来源与来源信任均位于 `_local/extensions`，不属于 Notebook 归档或知识备份。

## 下载边界

只允许无内嵌用户名/密码、无片段的 HTTPS URL，地址长度上限 2048 字符。每跳均复用公网 DNS 检查、指定解析 IP 与连接地址检查，禁止回环、私网、链路本地和保留地址；HTTPS 重定向不得降级为 HTTP，最多 3 次。TLS 使用 Node HTTPS 客户端默认验证，参见 [Node HTTPS 文档](https://nodejs.org/docs/latest-v24.x/api/https.html)。

最多 160KiB，通过响应长度与流式累计大小双重限制；拒绝非法 UTF-8、无效 JSON 和无效签名。整体下载 deadline 20 秒，最多同时 2 项下载；网络阶段运行在知识库写入队列之外。DNS 查询可能在底层继续等待，但取消后不会启动新的 HTTP 请求或生成审核。远程下载只属于应用的用户安装流程，未向第三方脚本开放网络 API。

当前支持公开地址分发、用户配置的 [扩展目录](EXTENSION-DIRECTORY.md) 和设备侧自动检查更新。私有仓库认证、中央市场运营与审核评级、静默自动安装、任意第三方 React/JS 宿主仍未实现。本次实现没有部署外部扩展服务。
