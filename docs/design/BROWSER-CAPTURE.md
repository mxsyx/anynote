# 浏览器采集

浏览器扩展帮助用户把网页选区或一段对话保存为笔记。先预览，再选择保存方式；正文与媒体的完整程度始终可见。

## 采集流程

1. 在网页中选中内容，通过“采集到 Anynote”打开侧栏；对话采集见[ChatGPT 对话](CHATGPT-CAPTURE.md)。
2. 检查标题、来源、正文和媒体清单，选择需要保留的内容。
3. 选择复制 Markdown、导出采集包或保存到云端。

只采集选中的正文及其必要结构，不扩展为整页抓取。列表、代码和表格尽量保留；无法转换的布局说明限制。选区已消失、页面无权限或不能访问时给出明确提示。

## 三种保存方式

| 方式          | 结果                             | 需要知道的边界                               |
| ------------- | -------------------------------- | -------------------------------------------- |
| 复制 Markdown | 便于粘贴的文字和可用链接         | 不携带二进制附件；私有或临时媒体改成缺失说明 |
| 导出采集包    | 正文、成功保存的媒体和完整性报告 | 在桌面导入时选择目录；专用格式不表示已加密   |
| 保存到云端    | 内容进入云端采集箱，可立即查看   | 在桌面执行“接收采集内容”后归入正式笔记本     |

媒体分别显示“已保存”“仅链接”“失败”“已跳过”。有缺失时，先重试或由用户明确选择保留缺失说明继续；只有完整性检查通过才标为完整采集。

## 侧栏与任务

侧栏分为采集和设置两个入口。切换时保留草稿和目标选择；设置入口集中管理云端连接、目录浏览与采集箱。界面使用清晰的白底、扁平布局和统一图标。

侧栏未能打开时，提示从扩展图标继续，不丢弃草稿。关闭侧栏会中止正在进行的媒体下载和采集包生成；重开后可读取已保存的草稿与媒体。未下载媒体的临时地址不持久保存，恢复下载可能需要重新采集。切换网页不会用新页面内容覆盖原任务。

大文件或存储空间不足时暂停并解释原因。导出前固定本次内容；之后编辑或重新采集应形成新结果，不能悄悄改写已经提交的内容。

## 权限与范围

普通网页在用户操作后访问，额外媒体站点按需授权。页面的登录信息只用于获准来源，不写入采集包或云端，也不传给其他媒体网站。

基础范围是 Chrome、Edge 的选区和单次对话采集；整站抓取、账号全部对话下载和云端编辑既有笔记另行规划。
