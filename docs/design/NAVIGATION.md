# 导航、目录与搜索

用户从书橱选择笔记本，再进入以正文为中心的工作区。目录、搜索和阅读导航帮助定位内容。

## 笔记本与目录

- 笔记本可以设置名称、图标和封面色；这些信息随资料一起携带。
- 创建笔记本使用默认位置或用户选择的位置，不覆盖已有文件。
- 外部磁盘断开时保留登记并显示不可用；移出工作区只取消登记，不删除原文件。
- 目录和笔记允许重名。身份不依赖标题或路径，移动后仍能被原链接找到。
- 拖动可以调整顺序或父目录，但不能移到自己的子目录中。
- 跨笔记本移动先完成目标复制，再将来源放入回收站。失败时保留来源，重试不重复复制。
- 删除目录会一起放入回收站；恢复只恢复这次删除的内容。原父目录仍在回收站时，恢复到笔记本根目录。

深层目录可以缩短章节编号，但要保留层级和完整标题的查看方式。大目录按可见范围呈现，不要求打开全部正文才能浏览。

## 搜索与定位

搜索覆盖标题、文字正文、标签和图片批注。PDF 只检索笔记标题、标签等元数据，文件内查找由系统查看器处理。可限定笔记本、标签、类型和更新时间；跨笔记本结果显示所属笔记本。

| 命中内容       | 打开后的行为                   |
| -------------- | ------------------------------ |
| 文字正文       | 按结果中的定位信息显示匹配内容 |
| PDF 标题或标签 | 打开系统 PDF 查看器            |
| 标题或标签     | 打开笔记                       |
| 无定位信息     | 正常打开笔记，不伪造正文命中   |

搜索结果显示文字摘要，选择结果后打开笔记。取消搜索或切换条件后，旧结果不能覆盖新结果。加载失败应显示错误，不能显示成“没有找到”。

内部链接按笔记身份定位，打开失败时显示错误并保留原链接。旧文件上的批注不能被当成当前文件的命中位置。

## 切换与辅助信息

- 前进、后退保留笔记及阅读位置，最多记录 100 次；从旧位置打开新内容后清除前进分支。
- 最多保留 30 个文档标签。隐藏标签栏不会关闭文档；关闭当前标签后打开剩余标签中的最后一个。
- 目录和标签均可通过键盘操作，切换前遵循[保存规则](DOCUMENT-SAVING.md)。
- 阅读区显示标题、标签与字数，历史和反向链接按需查看。
- 书橱按最近访问排列，区分本地、外部和不可用的笔记本。快照与备份状态在管理入口查看。
