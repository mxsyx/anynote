# 导航、目录与搜索

用户从书橱选择笔记本，再进入以正文为中心的工作区。目录、搜索和辅助面板帮助定位内容，不挤占主要阅读区域。

## 笔记本与目录

- 笔记本可以设置名称、图标和封面色；这些信息随资料一起携带。
- 创建笔记本使用默认位置或用户选择的位置，不覆盖已有文件。
- 外部磁盘断开时保留登记并显示不可用；移出工作区只取消登记，不删除原文件。
- 目录和笔记允许重名。身份不依赖标题或路径，移动后仍能被原链接找到。
- 拖动可以调整顺序或父目录，但不能移到自己的子目录中。
- 跨笔记本移动先完成目标复制，再将来源放入回收站。失败时保留来源，重试不重复复制。
- 删除目录会一起放入回收站；恢复只恢复这次删除的内容。原父目录已不存在时，提示恢复到笔记本根目录。

深层目录可以缩短章节编号，但要保留层级和完整标题的查看方式。大目录按可见范围呈现，不要求打开全部正文才能浏览。

## 搜索与定位

搜索覆盖标题、文字正文、标签、PDF 已提取文字和批注。可限定笔记本、目录、类型和更新时间；跨笔记本结果显示所属位置。

| 命中内容       | 打开后的行为                 |
| -------------- | ---------------------------- |
| 文字正文       | 滚动到匹配处并选中文字       |
| PDF 文字或批注 | 跳到对应页，突出显示匹配位置 |
| 标题或标签     | 打开笔记及属性面板           |
| 无定位信息     | 正常打开笔记，不伪造正文命中 |

快速打开提供跟随选择的文字预览；预览不加入导航历史。取消搜索或切换条件后，旧结果不能覆盖新结果。加载失败应显示错误，不能显示成“没有找到”。

内部链接失效时提供查找替代笔记的入口。确认后保留原链接文字并更新目标；取消不修改正文。旧文件上的批注不能被当成当前文件的命中位置。

## 切换与辅助信息

- 前进、后退保留笔记及阅读位置，最多记录 100 次；从旧位置打开新内容后清除前进分支。
- 最多保留 20 个文档标签。隐藏标签栏不会关闭文档；关闭当前标签后切到相邻标签。
- 目录和标签均可通过键盘操作，切换前遵循[保存规则](DOCUMENT-SAVING.md)。
- 属性面板提供标题、类型、时间、标签、字数、来源和位置；窄窗口下可随时关闭。
- 最近笔记本显示本机路径、访问时间和本地快照状态。云端或磁盘备份状态在备份入口单独显示。
