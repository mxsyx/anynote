# 导入与导出

导入让外部资料成为可管理的笔记；导出让用户能够带走资料。操作前说明范围，完成后说明是否有缺失。

## 网页与文件导入

用户可以提供网页链接、HTML 文件、文字或附件，选择笔记本和目录，查看预览后确认导入。网页可选择提取正文或尽量保留页面内容，后者不承诺复刻原网页排版。

确认提交使用用户刚刚预览的内容，不重新抓取网页并换成另一份结果。任务可取消，处理期间仍能继续使用笔记本。

本地 HTML 的相邻资源需要目录授权；普通网页导入不自动读取浏览器登录状态，也不绕过登录或付费限制。

## 媒体与缺失说明

- 成功下载的图片和附件可随笔记离线使用，并保留来源。
- 直接音视频可在限额内下载；平台播放器、流媒体或无法取得的资源保留链接并说明限制。
- 未下载、失败、用户跳过和仅保留链接分别列出，不能统称“已离线保存”。
- 失败媒体可单独重试。重试不覆盖用户后来编辑的正文；原占位内容已经变化时，提示跳过。
- 来源中的脚本不执行，文件只能在授权范围内读取；超出大小或空间预算时说明原因。

## 选择导出方式

| 方式                  | 适合用途               | 保留范围                                             |
| --------------------- | ---------------------- | ---------------------------------------------------- |
| 完整归档（.anynote）  | 搬迁、恢复和完整留存   | 正文、附件、历史、回收站、批注与持久业务状态         |
| 仅当前内容的归档      | 分享当前资料           | 明确排除历史、回收站和独立扩展状态，不夹带已排除内容 |
| Markdown 目录或压缩包 | 供其他工具阅读         | 当前内容、相对链接和附件，并报告无法保留的编辑能力   |
| 采集包（.anyclip）    | 搬运一次网页或对话采集 | 本次正文、成功取得的媒体及缺失说明，不是整本恢复包   |

完整归档默认包含历史。设备密码、云端令牌、授权、任务进度、临时文件和缓存不进入归档。

开放导出保留 PDF、图片原件；白板附原场景与预览，批注可附说明文件。它便于阅读，不承诺完整恢复所有能力。

## 安全完成与恢复

导出先在临时位置生成并校验，成功后才呈现为完成文件。导入先验证内容、格式、路径、完整性和空间，再登记为新的笔记本；失败或取消不留下可打开的半成品。

导入默认分配新的笔记本身份，并调整包内自指链接；指向其他笔记本的链接保留并说明未解析情况。未知内容保留，但不执行包内代码。

不支持的格式明确拒绝，不覆盖现有笔记本，也不借导入自动兼容任意历史版本或尝试危险的自动降级。
