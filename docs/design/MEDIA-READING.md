# PDF、图片与视频

原文件是资料的一部分。阅读位置、批注和显示方式可以变化，查看操作不能悄悄改写原件。

## PDF

PDF 作为只读资料交给系统 WebView 自带查看器打开。应用提供重新加载和原文件导出；翻页、缩放、文字选择、文内查找、密码输入及查看器工具栏由当前平台系统引擎提供，不承诺各平台功能和界面完全相同。系统查看器不可用或文件无法预览时，用户可导出原文件后使用其他阅读器打开。

桌面不再提供 PDF 批注、高亮持久化、关联笔记、页码/批注返回链接、全文索引或跨会话阅读位置恢复。全局搜索可以检索 PDF 笔记标题和标签；文件内文字查找留在系统查看器中。OCR、完整 PDF 编辑、原件写回与带批注导出不属于当前范围。

预览复用按笔记修订校验的资源读取，通过仅绑定回环地址、随机路径的临时 URL 流式提供当前 PDF；关闭视图即撤销 URL 并释放资源。查看器不接入业务 IPC、不获得资料库路径或应用凭据。文件读取和导出在后台完成；原文件不会因查看或导出而改变。

## 图片

图片笔记提供缩放、适应窗口、实际尺寸、平移、旋转查看、文件信息、说明和区域批注。

旋转查看只改变显示方向；明确另存修改时才产生新的文件版本。历史与批注继续绑定原先对应的图片，不能被最新图片替换。

超大图片先使用适合显示的预览，避免阻塞界面。带可执行内容的图片或网页格式只能安全预览或作为附件下载。

## 视频与采集卡片

视频先显示标题、封面和来源卡片。用户允许远程嵌入并点击播放后，才打开播放器；离线时仍可查看已有卡片，但不保证在线播放内容离线可用。

切换或关闭内容时停止播放并释放播放器。播放失败提供外部打开等恢复方式，同时说明嵌入播放没有成功。

采集卡片以受限内容呈现。未知卡片保留原始内容，不因此开放任意网页执行能力。
