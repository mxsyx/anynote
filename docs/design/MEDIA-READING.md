# PDF、图片与视频

原文件是资料的一部分。阅读位置、批注和显示方式可以变化，查看操作不能悄悄改写原件。

## PDF

PDF 阅读包括分页、缩略图、页码跳转、缩放、适应页面或宽度、文内查找和文字选择，并记住阅读位置。大文件按需加载页面。

选中文字后可以高亮、添加批注，或创建带返回位置链接的文字笔记。批注属于它创建时的文件版本；更换原文件后，旧批注保留在旧版本，重新定位需要明确操作。

提取文字用于搜索时，要区分完整、部分完成与没有可提取文字。扫描件不能被假称已经识别；OCR 属于另行规划的能力。密码只用于授权阅读，不随归档或备份导出。

任意 PDF 编辑、改写原文件和导出带批注 PDF 不属于基础阅读承诺。将来支持导出时，也应生成新文件。

## 图片

图片笔记提供缩放、适应窗口、实际尺寸、平移、旋转查看、文件信息、说明和区域批注。

旋转查看只改变显示方向；明确另存修改时才产生新的文件版本。历史与批注继续绑定原先对应的图片，不能被最新图片替换。

超大图片先使用适合显示的预览，避免阻塞界面。带可执行内容的图片或网页格式只能安全预览或作为附件下载。

## 视频与采集卡片

视频先显示标题、封面和来源卡片。用户允许远程嵌入并点击播放后，才打开播放器；离线时仍可查看已有卡片，但不保证在线播放内容离线可用。

切换或关闭内容时停止播放并释放播放器。播放失败提供外部打开等恢复方式，同时说明嵌入播放没有成功。

采集卡片以受限内容呈现。未知卡片保留原始内容，不因此开放任意网页执行能力。
