# 界面与交互

正文是主要工作区域。书橱、纸张和章节目录形成熟悉的阅读感，装饰保持克制；控件遵循原生桌面的操作习惯。

## 布局与视觉

书橱进入笔记本后，目录位于左侧，正文以合适宽度居中。右侧按需展开大纲、属性或反向链接，默认一次显示一个辅助面板，也可固定。

亮色和暗色主题共用字体、间距、文字层级与交互状态。纸张边缘和封面服务于阅读，不取代清晰的文字对比与焦点提示。

窗口变窄或文字放大时，优先保留正文；辅助区域可以收起或调整宽度，低频操作进入菜单。被收起的操作仍应有可发现的入口。

## 操作与反馈

- 常用操作保持可见，次要操作放在菜单；必要操作不能只在鼠标悬停时出现。
- 按钮写清动作和对象。删除、移出工作区、清理备份等不同结果不能共用含糊的说明。
- 菜单、工具栏和快捷键执行相同动作，是否可用取决于当前焦点、选区和只读状态。
- 加载、空内容、失败、离线和只读分别呈现；失败说明原因，并给出可行的下一步。
- 保存和备份状态分别显示，进度反映实际任务。已有结果清楚可见时，不再重复弹出成功通知。
- 有不可逆影响的操作先说明对象、范围和后果；可恢复操作优先提供撤销或回收站。

## 键盘与无障碍

所有主要流程都能使用键盘完成。焦点顺序符合阅读顺序，选中状态与悬停状态容易区分；状态不能只靠颜色表达。

弹窗打开后把焦点移到适当位置；Escape 关闭最上层可关闭的浮层，再把焦点交还原入口。图标按钮有可读名称，自绘正文和阅读器也要能被辅助技术理解。

界面适应中文长标签、系统字号和不同显示缩放。动效用于说明变化，并尊重减少动态效果的设置。
