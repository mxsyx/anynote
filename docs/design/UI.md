# 视觉组件与交互设计

桌面布局和组件以 [Rust 桌面方案](RUST-DESKTOP-MIGRATION.md)、[原生编辑器设计](RUST-EDITOR-DESIGN.md) 为准；书橱与纸张工作区的共同原则见 [ADR-010](adr/010-native-reading-layout.md)。

## 通用交互约束

- 统一亮/暗主题、字体、间距、文字层级、纸张边缘、焦点和危险状态；不在各功能中维护互相独立的视觉系统。
- 键盘行为和焦点始终可用；焦点不能依赖 hover，也不能被目录裁切。加载与动效尊重减少动态效果设置。
- 加载、空、错误分别呈现；错误提供可重试入口，不能误呈现为空结果。不为状态展示增加轮询或计时器。
- 书橱读取期间禁止依赖初始化完成的操作；搜索失败在搜索入口显示，缺失图片保留错误占位及重新读取入口。迟到结果不能写入已离开的页面。
- 收藏、最近、回收站及阅读器保留清晰空态；备份、导入和任务继续显示真实进度与失败原因。
- 搜索、创建、导入、恢复、迁移和媒体视图按需创建；关闭后释放对应资源，重型功能不增加启动开销。
- AI 面板的上下文范围、引用、可读变更及接受/拒绝/撤销属于 [远期设计](Anynote-Design.md#17-ai-能力预留)，不作为现有功能承诺。

原生输入、读屏、焦点、窗口尺寸和主题的实际验收见 [RM32](../development/TODO.md#rm32)；自动化通过不能代替人工验收。
