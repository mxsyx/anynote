# 界面与交互

正文是主要工作区域。目录和工具需要可达，但不能让用户在多个窄栏之间寻找正文。笔记本是工作区的顶层对象，装饰保持克制；控件遵循原生桌面的操作习惯。

## 布局与视觉

启动直接进入上次使用的可用笔记本；该笔记本不可用时，选择最近访问或列表中的可用笔记本。首次没有笔记本时显示新建与打开入口，不设置独立的笔记本总览页。

顶部栏显示当前笔记本，通过下拉菜单切换、新建、打开及设置笔记本；外部笔记本可取消登记，文件保留。菜单标记当前项和不可用项。切换前等待草稿保存，保存失败时保留当前内容。

参考 quiet-md 的布局关系：中性浅灰侧栏与完整正文区域并排，使用细分隔线和紧凑工具栏。侧栏将全部笔记、最近、收藏、标签、回收站纵向排列，目录按可见范围渲染；宽度可以调整，也可从顶部隐藏。未选中笔记时显示当前笔记本名称、内容数量和最近更新的 12 篇笔记。阅读区提供大纲、历史和反向链接；文字编辑与媒体阅读通过对应入口打开。

亮色和暗色主题共用字体、间距、文字层级与交互状态。主内容使用亮色白底或暗色深灰底，侧栏与工具栏使用语义主题色；选中、悬停和键盘焦点保持清楚。

窗口变窄或文字放大时，优先保留正文；辅助区域可以收起或调整宽度，低频操作进入菜单。被收起的操作仍应有可发现的入口。

标签、前进后退和搜索定位共用笔记身份，具体规则见[导航、目录与搜索](NAVIGATION.md)。

## 操作与反馈

- 常用操作保持可见，次要操作放在菜单；必要操作不能只在鼠标悬停时出现。
- 按钮写清动作和对象。删除、移出工作区、清理备份等不同结果不能共用含糊的说明。
- 菜单、工具栏和快捷键执行相同动作，是否可用取决于当前焦点、选区和只读状态。
- 加载、空内容、失败、离线和只读分别呈现；失败说明原因，并给出可行的下一步。
- 保存和备份状态分别显示，进度反映实际任务。已有结果清楚可见时，不再重复弹出成功通知。
- 有不可逆影响的操作先说明对象、范围和后果；可恢复操作优先提供撤销或回收站。

## 键盘与无障碍

所有主要流程都能使用键盘完成。焦点顺序符合阅读顺序，选中状态与悬停状态容易区分；状态不能只靠颜色表达。

弹窗打开后把焦点移到适当位置；Escape 关闭最上层可关闭的浮层，再把焦点交还原入口。图标按钮有可读名称，自绘正文和阅读器也要能被辅助技术理解。

界面适应中文长标签、系统字号和不同显示缩放。动效用于说明变化，并尊重减少动态效果的设置。

视觉统一不能代替真实窗口中的输入法、键盘和屏幕阅读器可用性。
