# ADR-012 · 备份服务装配与存储单向依赖

状态：采用。[返回 ADR 索引](README.md)

## 背景

存储层反向加载备份业务会形成依赖环。延迟加载只能改变执行时机，不能解决责任与依赖方向。

## 决定

Rust 应用服务层装配存储、快照、本地/云备份、任务和调度。存储层提供租约、事务、CAS、资源闭包与冻结切面，不反向依赖 UI 或备份服务。

写入与一致性切面捕获通过同一写队列；大文件复制、哈希、网络传输和恢复在服务工作线程执行。任务重试复用业务回执与相同协议，避免队列递归等待和重复提交。

快照校验 Notebook 身份、schema、受管路径、序列号及资源闭包。取消、超时和预算贯穿调用链，不能以进程退出或未知响应推断任务成功。

## 取舍与边界

装配层负责业务组合，不新增仅转发调用的兼容包。Rust 工程边界见 [目标架构](../RUST-DESKTOP-MIGRATION.md)，服务契约见 [快照与归档](../../development/RUST-SNAPSHOT-ARCHIVE.md)、[本地备份](../../development/RUST-LOCAL-BACKUP.md)。
