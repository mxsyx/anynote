# ADR-012 · 存储与备份各负其责

## 为什么

如果基本保存依赖备份服务，网络和长任务的故障容易影响本地编辑，职责也难以厘清。

## 决定

存储负责安全保存资料和提供一致快照；备份负责比较、传输、验证与恢复；应用协调任务与状态。存储不反过来依赖界面或备份流程。

长时间的文件处理和网络传输在后台进行，取消与失败有明确结果。

## 取舍

分工需要清晰的协作边界，但不需要每个功能都维护另一套任务和数据状态。未知结果必须核对，不能因退出就判定成功。
