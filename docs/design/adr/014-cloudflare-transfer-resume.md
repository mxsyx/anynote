# ADR-014 · 续传前重新确认内容

## 为什么

只有远端已经存在一些文件，并不足以证明重启后可以安全接着传；资料、目标或权限可能已经变化。

## 决定

保存不含凭据的传输进度。继续前重新确认连接、笔记本、版本、权限和文件内容，身份一致才复用已验证进度。

下载缓存也要重新校验，损坏部分重新下载。完整内容通过检查后才能作为恢复结果；失败或取消可保留进度供重试。

## 取舍

续传减少网络量，但仍需要读盘、临时空间，也可能重发最后一段。它不承诺从任意字节恢复，取消也不表示任务继续执行。
