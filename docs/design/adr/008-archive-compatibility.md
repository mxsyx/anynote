# ADR-008 · 完整归档与安全导入

## 为什么

用户需要完整带走资料，同时导入包不能覆盖现有笔记本或执行不可信内容。

## 决定

完整归档默认包含正文、附件、历史、回收站、批注与持久业务状态，排除设备凭据、授权和任务进度。

仅当前内容与开放 Markdown 导出是不同选择，需要明确说明省略范围。导入先校验全部内容，成功后创建新笔记本；未知内容保全但不执行。

## 取舍

开放导出便于其他工具阅读，但不等于完整恢复格式。不支持的格式明确拒绝，不借导入自动兼容任意历史版本。
