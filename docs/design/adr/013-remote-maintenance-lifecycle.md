# ADR-013 · 清理需要预览与确认

## 为什么

永久保留未完成上传会占用空间；删除全部记录又可能让迟到请求重新发布旧内容。

## 决定

清理先生成预览，确认时重新检查对象和条件。当前版本、其他分支以及正在上传或恢复的保护范围不能误删。

保留必要的删除与完成记录，阻止旧请求重新生效。每个目标记住数量及日、周、月保留设置，但保存设置不自动执行删除。

## 取舍

保留记录本身会持续占用空间。空间估算需要说明未完成上传等未计入的部分；达到限额时不能通过削弱保护规则继续运行。
