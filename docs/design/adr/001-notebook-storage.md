# ADR-001 · 每本笔记本独立保存

## 为什么

用户需要单独搬运、备份和恢复某个主题的资料，不应依赖其他笔记本才能打开。

## 决定

每本笔记本使用自己的数据库和附件目录，身份与内容一起保存。设备设置独立存放；同一笔记本只允许一个应用实例写入。

目录保持稳定的同级顺序，移动时完整更新关系。浏览大目录只需加载必要信息，不要求同时打开全部正文。

## 取舍

独立保存便于隔离与恢复，但跨笔记本操作需要分别确认。文件锁也不能让任意网络磁盘天然适合作为工作目录。
