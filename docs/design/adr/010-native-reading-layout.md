# ADR-010 · 原生阅读布局与辅助面板

状态：采用。[返回 ADR 索引](README.md)

## 背景

应用采用书橱到笔记本的阅读流程，保持原生桌面操作和克制的拟物层次；正文应是主任务。

## 决定

书橱进入工作区，章节目录在正文左侧，纸张限宽居中，侧边辅助面板按需展开。文档标签、导航历史、属性与搜索定位保留；设置、备份与内置业务通过原生入口访问。编辑器、PDF、图片和白板按需创建。

亮/暗主题、字体和交互状态由统一视觉体系维护。Rust 组件及主题遵循 [桌面设计](../RUST-DESKTOP-MIGRATION.md)，不沿用旧 CSS/React 实现约束。

## 取舍与边界

主题与控件检查不能替代真实 IME、读屏和跨平台视觉验收。共同状态规则见 [视觉与交互](../UI.md)，任务状态见 [TODO](../../development/TODO.md#rm32)。
