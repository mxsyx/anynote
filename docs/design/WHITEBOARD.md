# 白板

白板是可继续编辑的图文场景。预览图用于快速阅读，不能替代原有图形、文字和关系。

## 编辑体验

白板保留原有可用工具：基础图形、文字、手绘、线与箭头、图片、选择与多选、组合、层级、样式、复制粘贴、撤销重做，以及缩放和平移。

箭头与图形的连接、组与容器的关系、图片裁剪和文字位置都属于内容。移动、缩放或重开后，这些关系应继续成立。

已有场景中的未知属性和内容需要保留。某类内容可以保留或预览，不等于已经具备它原先的编辑能力。

## 保存与历史

白板使用明确的“保存”动作。关闭视图本身不自动提交未保存的修改，也不能把预览生成成功当成保存成功。

保存时先处理正文草稿，再核对目标白板是否仍是打开时的版本。若正文或白板已被其他操作修改，提示冲突，不覆盖新内容。

一次保存包含白板场景、嵌入图片、预览和对应笔记版本。历史笔记打开历史白板时，必须看到当时的图片和场景。

## 设计取舍

Excalidraw 在系统 WebView 中独占图形编辑状态、选区、工具和撤销历史。Rust 不再维护另一套绘图、命中和操作内核，只负责修订资源、保存校验与事务。保存时从同一个冻结场景生成 JSON 与 PNG，成功后返回更新的笔记；失败保留草稿，未知提交结果使用原请求重试。

前端资源和字体随程序交付，首次使用无需下载编辑器。系统 WebView 的真实输入、输入法、多屏 DPI、剪贴板和无障碍能力仍须逐平台验收；功能入口存在不等于设备验收已完成。

在线协作和在线 AI 绘图不因保留白板格式而自动成为产品能力。
