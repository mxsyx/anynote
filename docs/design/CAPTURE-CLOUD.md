# 云端采集与只读浏览

云端让桌面离线时也能收集资料。正式笔记仍由桌面保存，浏览器看到的笔记来自已经发布的备份。

## 连接与授权

“连接 Anynote 云端”是连接用户自己的 Anynote 服务，不要求浏览器扩展保存 Cloudflare 账号密码或管理密钥。

桌面生成短时、一次性的配对码。扩展配对后只获得指定笔记本和分支的浏览、创建采集及读取自身采集权限，不能接管备份写入或执行清理。

设备授权可撤销，失效后需要重新配对。授权只在当前浏览器会话保存，结束会话后需要重新配对。

## 不同状态代表什么

| 状态                 | 对用户的含义                         |
| -------------------- | ------------------------------------ |
| 草稿或上传中         | 内容还没有完整保存到云端             |
| 已保存到云端，待归入 | 可在采集箱阅读；尚未成为本地笔记     |
| 需要重新选择目录     | 原目标不可用，需要用户重新指定       |
| 已归入               | 桌面已成功保存笔记，云端备份尚未确认 |
| 已备份               | 包含这次采集的完整备份已经发布       |

在桌面执行“接收采集内容”后，采集才归入正式笔记本；包含该内容的云端备份发布后，才确认已备份。连接云端本身不完成归入。

重试同一次采集不会重复创建笔记。已领取处理中或已归入的任务不能直接改投目录；原目录失效时，不能偷偷改投笔记本根目录。

尚未归入或尚未备份的内容不能因常规备份清理而消失。已完成任务保留确认记录；恢复较旧备份时，不自动重复导入已经完成的采集。

## 浏览已备份资料

侧栏读取配对授权所对应的笔记本与分支，再按目录读取正文与媒体。界面显示备份时间；目录、正文和图片必须来自同一个备份版本。

最新备份没有可浏览内容时，提示从桌面发布新备份，不能显示成空笔记本，也不能把旧版本冒充最新内容。

只读浏览不包含回收站、本机路径、设备设置或凭据。查看权限到期或版本不再可用时，提示刷新；不能改读其他版本的资源来拼凑当前页面。

## 设计边界

采集箱和笔记本备份是不同对象。浏览数据生成失败不妨碍有效备份发布，也不能因此虚报采集已备份。

浏览器不直接修改既有笔记，多设备自动合并不属于本方案。重新配对产生新设备身份，不能仅凭相同名称读取旧设备的私有采集。
