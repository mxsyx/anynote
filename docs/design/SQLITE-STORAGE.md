# 本地资料与历史

每个笔记本拥有独立的数据库和附件目录，可以单独携带、备份和恢复。工作区只登记它们的位置，不把全部知识混在一个总数据库中。

笔记本身份与内容一起保存。目录保持稳定的同级顺序，移动时完整更新关系；浏览大目录只加载必要信息，不要求同时打开全部正文。

## 什么随笔记本保存

| 随资料携带                       | 留在当前设备                 |
| -------------------------------- | ---------------------------- |
| 标题、正文、目录顺序、标签与收藏 | 最近打开位置、窗口和阅读偏好 |
| 历史版本、回收站与批注           | 任务进度、连接设置和诊断信息 |
| 附件及每个历史版本对应的文件     | 密码、令牌与本机目录授权     |
| 持久业务内容和未知内容的原始数据 | 临时预览与缓存               |

搜索索引和已提取的 PDF 文字随笔记本数据库保存。它们用于检索，不能替代原文或附件。

搬运笔记本需要完整资料，不能只复制数据库文件。运行中的笔记本通过一致性快照导出，避免复制到一半新、一半旧的内容。

## 附件为何保留旧版本

附件一经保存就不覆盖原文件，避免旧笔记和批注被替换成新内容。修改图片或白板会产生新版本；笔记里的资源身份可以保持稳定，但每个历史版本固定自己需要的文件，改名或移动笔记不影响它。

相同内容在同一笔记本内可以复用，但不同笔记本不共享必须共同维护的附件生命周期。

新附件先安全落地，之后才保存引用它的笔记。失败可以留下等待清理的文件，但不能让保存成功的笔记指向不存在的附件。

## 保存与清理

同一笔记本只允许一个应用实例写入，避免新旧程序同时修改。磁盘已满、目录只读或文件损坏时，明确报错并保留可恢复的内容。

删除笔记先进入回收站。备份包含当前内容、历史与回收站仍需要的附件。永久清理还要检查历史、回收站、快照和正在进行的导出、备份，仍被需要的附件不能删除。

发现未知文件或中断任务的残留时先报告，不按文件名猜测并自动删除。损坏资料先保全原件，再诊断和恢复。

## 设计取舍

独立笔记本便于迁移和恢复，但跨笔记本操作需要分别确认。原始工作目录不依赖网盘同步或网络磁盘提供写入安全，远程保护通过备份完成。

保留旧附件需要额外空间和明确的清理规则，不能只看当前页面是否引用某个文件就删除它。
