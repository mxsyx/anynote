# 本地磁盘备份

磁盘备份在用户选择的目标上保留当前完整副本。每次更新尽量复用未变化内容，但恢复不依赖以前的副本。

## 目标与范围

用户可以选择备份目录、笔记本范围和计划，并在执行前查看预计空间。来源与目标不能相互包含，备份目录也不能直接作为工作笔记本编辑。

应用需要辨认实际设备和备份目标。磁盘断开、换盘、重新挂载或空间不足时，应暂停并说明原因，不能只凭相同盘符继续写入。

## 更新规则

1. 获取当前笔记本的一致快照。
2. 比较已有内容，写入并校验新增部分。
3. 新副本完整且安全保存后，才把它设为当前备份。
4. 最后清理原副本中已不需要的受管文件。

新副本发布前失败，保留原副本。发布后清理失败，显示“备份已更新，清理待重试”，不能将有效备份误报为丢失。

中断后只处理能够确认由本次备份管理的残留，不扫描删除用户的其他文件。显式完整校验会重新检查内容，不能只信任文件没有改名或大小未变。

## 恢复与移除

恢复在独立位置完成全部验证后创建新笔记本。移除备份目标与删除备份副本是两个动作，界面必须说明差别。

批量任务按笔记本报告结果，一部分失败不能掩盖其他结果，也不能显示为全部成功。
