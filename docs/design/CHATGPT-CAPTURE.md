# ChatGPT 对话采集

用户在当前对话页发起采集，预览当前选中分支的用户与助手消息，再决定保存。其他重新生成或编辑产生的分支不混入结果。

## 内容范围

- 保留消息角色、顺序、文字、代码、表格、数学源码和可见引用。
- 图片、附件和其他媒体逐项处理；无法取得或转换的部分明确列为缺失。
- 引用与工具结果只包含网页已经向用户展示的内容。
- 不包含系统消息、开发者消息、隐藏推理、内部工具数据或登录凭据。
- 仅补充能与对应消息确认关联的已显示图片，不重新搜索，也不把页面其他图片混入对话。

数学源码保留不等于已经支持完整数学排版。复杂卡片可以安全呈现或保留原始内容，但不能执行其中的网页代码。

## 分支与生成中内容

按页面可识别的末条消息定位分支；没有可用的页面消息标识时，使用对话返回的当前节点，再沿父消息读取该分支。页面消息与对话节点不一致时停止采集，提示刷新后重试。

正在生成的内容作为未完成快照列入缺失说明；用户明确允许保留缺失说明后，才能导出或上传。希望保存完整结果时，需要等待生成结束再重新采集。历史链缺失或超过限制时停止采集并提示原因。

临时媒体链接需要在会话仍有效时取得文件。只保留一个可能过期的地址，不算已经保存附件。

## 失败与恢复

这是一项依赖 ChatGPT 网页环境的实验适配，不能把普通 OpenAI API 密钥当作网页登录。网页接口变化、权限不足或访问受限时，停止相应读取，保留草稿并说明原因。

页面关闭或跳转后，不继续使用旧页面会话。用户也可通过普通网页选区采集保存可见内容；它与完整对话采集的范围不同。

采集不绕过登录、验证码或工作区权限；会话凭据不进入扩展持久存储、日志、采集包或云端。
