# 文字编辑

默认提供连续文档：用户直接在排版后的内容中输入、选择和修改。源码编辑是处理特殊语法的辅助入口，按需打开。

## 编辑能力

| 内容 | 主要操作 |
| --- | --- |
| 段落与标题 | 输入、换行、调整标题级别、移动内容 |
| 文字格式 | 粗体、斜体、删除线、行内代码与链接 |
| 列表 | 有序、无序、任务勾选与嵌套 |
| 表格 | 单元格编辑、键盘导航、增删行列和粘贴 |
| 其他内容 | 引用、代码块、分隔线、图片、白板与视频卡片 |

输入斜杠可打开插入菜单，Markdown 标记也可触发相应格式。菜单、工具栏和快捷键遵循同一套行为，插入后光标留在可以继续写作的位置。

笔记标题与正文中的一级标题相互独立，修改其中一个不会自动改名另一个。

## 保留原文

正文以 Markdown 保存。打开后没有修改，就不应改动原文；局部编辑只改变必要范围，其他文字、空行和未识别内容保持原样。

遇到暂不支持直接编辑的语法、卡片或新版本内容时，保留原文和附件，说明限制，并提供查看、复制、源码编辑或导出入口。不能把未知内容替换成空白或提示文字后保存。

源码视图与连续视图编辑同一份文档，共用撤销、选区和保存状态。切换后尽量回到原阅读位置，不出现两份互相覆盖的正文。

## 输入、选择与撤销

- 支持跨段选择、复制粘贴、撤销和重做；一组粘贴或格式操作作为一次可撤销动作。
- 中文等输入法的候选文字在确认后才成为正式修改。选词期间不触发插入命令、格式转换或自动保存。
- 光标、删除与选区遵循用户看到的完整字符，不拆开组合字符或表情。
- 粘贴网页内容先转成安全的文字、列表或表格；粘贴图片和拖入文件按附件处理，不执行来源代码。
- 键盘和屏幕阅读器应能识别正文结构、链接、图片说明及任务状态。

## 大文档

长文档只呈现当前需要的部分，搜索仍可定位屏幕外内容。超出连续编辑能力时，明确提供源码处理路径，保留全文，不截断输入。

正文滚动、表格横向滚动和代码块滚动各自符合所在区域。窗口缩放或图片加载后，光标、选择和输入法候选位置仍应正确。
