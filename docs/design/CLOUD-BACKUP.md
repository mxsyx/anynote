# 云端备份与维护

云端保存完整、可恢复的版本，并复用未变化的内容。用户自己的 Cloudflare 服务是备份目标，正式笔记仍在本机编辑。

## 发布一个版本

上传了部分文件不代表已经形成可恢复的版本。先准备、上传并验证所有必要内容，再一次性发布完整版本。恢复列表只展示已经完成的版本，冲突或校验失败不发布，上传中途失败不影响之前的有效版本。

提交后没有收到回应时，先查询同一次备份的结果，不能直接判断失败并重复发布。

额外的准备和校验步骤换来明确的恢复边界。失败上传可能留下需要清理的临时内容，但不能用半成品替换有效版本。

## 续传与重试

远端已有部分文件，不足以证明重启后可以安全续传。设备保存不含凭据的传输进度；继续前重新确认连接、笔记本、版本、权限和文件内容，身份一致才复用已经验证的进度。资料、目标或权限已经变化时，不能沿用旧进度冒充同一任务。

下载缓存也要重新校验，损坏部分重新下载。完整内容通过检查后才能作为恢复结果；失败或取消可以保留进度供重试。

续传主要节省网络传输，仍需要读盘校验和临时空间，也可能重发最后一段，不承诺从任意字节恢复。取消不代表任务仍在后台执行。

## 设备与分支

同一分支只接受当前获授权设备发布。另一台设备接管必须由用户明确选择；接管后，原设备不能再覆盖新版本。

检测到分支已有新内容时，提示冲突，不自动覆盖，也不自动合并。恢复默认创建新笔记本；是否继续原分支另行决定。

## 保留与清理

- 每个目标可设置保留数量，以及按日、周、月保留的范围。
- 保存保留策略与确认删除分开进行，保存设置不等于授权自动删除。
- 清理前展示拟删除版本和预计空间，确认时重新检查条件是否仍有效。
- 当前版本、其他分支、正在上传或恢复的受保护内容不能误删。
- 长期未活动的上传可以进入手动清理预览；活动清理任务不能仅因经过一段时间就被另一任务强行接管。
- 保留必要的删除和完成记录，防止迟到请求让已删除版本重新出现。

未完成上传可能占用空间，保留的删除和完成记录也会随历史增长持续占用空间。清理预览应说明未计入估算的部分。远端容量不足时报告限制，不削弱保护规则来腾空间。

## 恢复与隐私

恢复固定一个完成版本，校验全部正文和附件后才登记。查看或恢复期间临时保护所用版本；保护失效时先处理错误，不能继续拼接不完整内容。

云端对象默认私有，但普通云备份不等于端到端加密。应用凭据与服务部署凭据分开管理。
