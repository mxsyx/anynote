# 保存、冲突与历史

“已保存”表示内容已经成功写入本机。云端备份是否完成，是另一项独立状态。

## 什么时候保存

文字编辑在短暂停顿后自动保存。手动保存、离开笔记、失去编辑焦点和退出应用时，都要处理尚未保存的内容。

输入法仍在选词时，先等待确认或取消，再保存最终文字。不能因为窗口正在关闭就跳过这一步。

保存期间允许继续输入。较早的保存结果只能确认当时的内容，不能覆盖后来输入的文字；仍有新修改时继续显示待保存。

## 失败与冲突

| 情况                     | 应有的结果                                   |
| ------------------------ | -------------------------------------------- |
| 磁盘已满、只读或写入失败 | 保留草稿，说明原因，提供重试、另存或导出路径 |
| 另一处已修改同一笔记     | 保留两边内容，提示比较或恢复，不直接覆盖     |
| 保存请求发出后失去连接   | 先确认实际保存结果，再决定重试               |
| 退出时仍未保存           | 等待保存，或由用户取消退出、明确放弃修改     |
| 后台服务异常             | 保留仍在界面中的草稿，恢复连接后核对最新内容 |

应用崩溃后，只能保证恢复已经成功保存的内容；最近尚未保存的输入可能丢失。更强的草稿恢复属于单独规划的能力。

## 历史与附件

撤销处理当前编辑动作，历史版本用于查看和恢复已经保存的内容。恢复旧版本会产生一个新版本，不抹去中间历史。

图片和白板更新时，正文与对应附件作为一个完整结果保存。失败不留下指向半成品的笔记；历史版本仍使用当时的附件。

切换笔记后，迟到的保存或媒体处理结果只能属于原笔记，不能写入当前打开的另一篇。
