# 编辑器与扩展生态

本轮继续使用 Markdown 为唯一正文真源，Tiptap 模型只派生自当前块。富文本保持 Beta：保存只规范化用户编辑的块，其他正文、未知指令属性和未知 JSON 字段保留。

## 编辑器

- 富文本支持段落、标题、粗体/斜体/删除线、列表、引用、代码、链接、GFM 任务列表与普通表格。表格可增删行列，任务可勾选，当前块支持撤销/重做。
- 选区浮动工具提供格式化；输入 `/` 可选择标题、列表、任务列表、表格和代码块。块上移/下移与拖拽保持块原文，必要时补齐 Markdown 分隔空行。
- 源码工具提供搜索替换、选区加粗/斜体/代码/链接。切换模式先提交草稿，提交失败保持当前模式；组合输入期间拒绝切换。切换后在预览/源码/富文本间按相对比例恢复阅读位置。
- 首发语法边界为 CommonMark 加选定 GFM 子集：段落、标题、强调/加粗、行内代码、链接、硬换行、引用、普通/嵌套列表、代码块、分隔线、删除线、GFM 表格与任务列表。协议层以 `richSyntax` 导出该边界供核对。
- 边界之外一律保留原文并就地提示降级原因（`RichBlockReason`），导向源码编辑：对齐表格、混排/远程图片、HTML、脚注、引用式链接与定义、含反斜杠转义的文本、带额外元数据的代码与未识别扩展。块编辑预算 500,000 字符；大文档沿用源码策略。
- 未知扩展显示原文并可下载该块。已安装、启用且授权的声明式节点提供文本字段表单、提示卡或折叠显示；编辑已知字段时保留其他数据。

块拖拽与独立本地图片宽度编辑已实现；任意 Markdown 完整富文本往返及真实中文输入法人工验收尚待完成。自动测试的组合事件用于验证模式保护，不代表操作系统输入法验收。白板、图片资源导入及视频卡片沿用已有能力。

## 安装声明式扩展

1. 打开「设置 → 扩展」，选择 JSON 文件，检查名称、版本、权限及完整贡献定义，再确认安装。
2. 授权当前 Notebook。全局启用决定设备上是否可用，每库开关可单独停用；授权与开关分别控制。
3. 在 Markdown 笔记中按 `Ctrl+K`，点击扩展命令。命令先提交当前草稿，再使用版本条件写入当前笔记。
4. 在富文本中编辑扩展字段。停用或卸载后指令仍存在，使用原文降级显示。

示例：[阅读卡片](../packages/plugin-sdk/src/examples/reading-callout.json)。支持 `appendMarkdown`、`insertBlock` 两种命令，节点使用 `callout` 或 `details` 和声明的文本字段；第三方 JSON 不执行脚本、HTML、任意 React 或原生代码，也不取得网络、文件、密钥权限。

扩展 ID、贡献命名空间、引擎版本和权限均严格校验，保留首方命名空间。安装/更新会清除之前的设备授权；操作绑定清单 SHA-256，过期界面不能执行更新后的命令。校验和用于绑定审核版本，并非发布者签名。命令回执与正文在同一知识事务提交，同一操作 UUID 重试不会重复插入。

清单最多 128KiB，每设备最多 64 个扩展；每扩展最多 30 个命令、20 个节点、每节点 10 个字段。扩展目录、清单与授权保存在设备 `_local/extensions/registry.json`，不进入 Notebook 导出或云备份；每库启用覆盖和指令正文属于知识数据。恢复到另一设备后需重新安装和授权。卸载保留知识数据和历史。

## 独立 SDK

```sh
pnpm run build:sdk
npm pack ./artifacts/plugin-sdk
pnpm run test:sdk:package
```

构建产物提供 ESM 与生成的 TypeScript 声明，公开 API、上下文和声明式清单类型，不包含 SQLite/Electron/Node 宿主或运行时依赖。可从本地 tarball 安装；本轮未发布到 npm。受信首方宿主沿用有限能力和 Notebook 约束，激活异常会清理已注册命令，停用后旧上下文失效，旧释放函数不会移除新会话注册。

通用第三方 JS/React 宿主、签名分发、市场、热更新和完整包级发布矩阵仍未实现；后续补充了受限正文转换脚本。独立 SDK 的 API 合约不代表桌面已开放第三方可执行模块安装。

## 块拖拽与图片尺寸补充

富文本块的拖动手柄支持放到另一块之前/之后，上半部表示之前，下半部表示之后。上移/下移按钮保留键盘路径。编辑块或组合输入期间不允许移动；拖拽绑定当前 Notebook、笔记、正文及会话令牌，拒绝旧会话与外部拖拽数据。移动保留每个块原文，只在必要时补齐空行；调整范围以外正文不变。

独立本地 Markdown 图片可点击「编辑此块」设置 32–4096 整数像素宽度或自适应。窗口较窄时按容器缩小，始终保留原图及宽高比例。第一次设置尺寸将普通图片转换为 `core.image` v1 扩展块：

```markdown
:::anynote{type="core.image" version="1" id="块 UUID"}
{"resourceId":"资源 UUID","alt":"说明","title":"原有标题","width":320}
:::
```

尺寸修改保留指令的未知属性与 JSON 字段，自适应只移除 `width`。正文资源引用继续参与版本资源闭包、完整归档与恢复。开放 Markdown 导出生成普通图片引用和原图文件，导出报告说明显示尺寸会丢失。未知版本或非法尺寸使用原文降级；混排、引用式与远程图片继续使用源码编辑。当前不提供自由裁剪、旋转写入或直接拖动图片边缘缩放。

本轮新增三项合约检查，完整回归共 101 项；桌面流程新增实际鼠标拖拽及图片尺寸持久化/阅读态渲染，包含尺寸表单的无障碍扫描。生产页面及打包版报告仍写入上述同名文件。

新增图片尺寸表单截图：`docs/screenshots/editor/image-width.png`。新增集成检查亦确认跨 Notebook 复制会重新分配资源身份，图片宽度和原图字节保持不变。

本轮最终结果：生产页面与 Linux 打包版各 9 项编辑器流程、5 次无障碍扫描通过；最新打包版既有性能/界面 15 项及 36 次扫描通过，自动违规均为零。旧客户端可保留 `core.image` 原文与资源，但不会显示其尺寸；完整恢复不依赖渲染该块。

## PDF 阅读与文本任务（2026-10-06）

阅读器在原有分页、缩放、文字选择、文内搜索、高亮/批注、密码与阅读位置之上补齐阅读辅助与文本索引边界：

- 页缩略图面板可收起；缩略图只在滚入视口时解码（`IntersectionObserver`），点击跳页并标记当前页。
- “适应宽度/适应页面”按滚动容器实时尺寸计算缩放，窗口变化时重算；手动缩放回到自定义比例。
- 选区可保存高亮批注，也可“创建关联笔记”：新增 `createPdfNote` 在同一事务写入批注与一篇 Markdown 笔记，笔记正文包含引用片段与 `anynote://…/#pdf-page-N`（或 `#pdf-annotation-<id>`）返回链接。点击返回链接经应用内部导航把锚点交回阅读器，恢复到对应页；锚点按笔记 ID 绑定，普通树导航不会误用旧锚点。
- 文本抽取/索引登记为可取消的 `pdf-index` 后台任务（`beginPdfIndex`），同一笔记复用进行中的任务；抽取按页上报进度，任务中心可取消，取消或失败时丢弃部分结果，成功时由 `indexPdf` 结算并按 `pdfIndexCoverage` 区分完整索引、部分索引（前 500 页/正文预算）与扫描件（OCR 未启用）。文内搜索在页数超限时提示“已搜索前 N 页”。
- 资源换绑后批注不自动套用：批注继续绑定旧哈希并以“旧版本”标记保留，`createPdfNote`/`addAnnotation` 拒绝过期哈希，只有显式“重新锚定到当前版本”（`reanchorAnnotation`）才迁移到当前版本。

合约与回归：新增 `packages/protocol/src/pdf.ts` 纯函数（索引预算/覆盖状态、页码与批注锚点、关联笔记正文、批注新旧哈希分组），`tests/pdf-reader.test.mjs` 覆盖覆盖状态、锚点往返、关联笔记与旧哈希保护/重新锚定、可取消 `pdf-index` 任务的部分索引与丢弃边界；`scripts/editor-ecosystem-smoke.mjs` 新增多页合成 PDF 桌面流程，覆盖缩略图跳页、适应切换、完整索引提示、创建关联笔记与返回链接回跳。真实扫描件、复杂字体向量、加密 PDF、超大文档与跨设备阅读验收仍需人工完成。

本轮同时修正了模式切换阅读位置恢复的一处缺陷：模式切换后的新内容尚未完成布局（滚动范围为 0），原实现只写入一次会导致位置被清零；现在恢复会等待滚动范围就绪后再落地，并避免与用户交互争抢。该检查（含此前因 `scroll-behavior: smooth` 与测试点击自动滚动而不稳定的断言）已稳定通过，编辑器桌面验收全绿。
