# 本地磁盘备份设计

当前实现采用单 SQLite 与数据库物理分块，具体契约见 [存储设计](SQLITE-STORAGE.md) 和 [本地备份实现](../packages/backup-local/README.md)。

流程为：一致性捕获 → 校验并计算有序块 → 比较受管块 → 持久化写入日志 → 写后校验 → 原子发布完整清单 → 清理旧块。只保留当前完整副本，恢复创建新 Notebook。所有新增数据均在 Notebook SQLite 内，目标不保存目录型附件或引导 JSON。

目标初始化、目录授权、身份校验、空间预算、任务进度/取消、设备重新挂载检测、范围配置和批量部分失败沿用宿主能力。分块列表属于完整快照，每次恢复独立于早期清单；旧块只有在新清单持久化后才可删除。

旧清单重建、整库替换协调、附件删除比例审批和旧格式兼容已移除。变更为开发期破坏性格式升级，无自动迁移。
