2026-10-21；源码基线 `b06b0a0` 加本组工作区改动。旧 T057 已完成并移出待办，实施交接见 [历史记录](history/todo-2026-10-24.md#g20)。

## 设计契约

沿用 [ADR-010](adr/010-native-reading-layout.md) 的亮/暗主题与书橱 → 纸张工作区结构。此次不改变配色方向、导航和编辑器模型。

- `styles.css` 是应用语义 token 来源：`--font-ui`、`--font-book`、`--font-code`、间距、文字大小、纸张边缘/阴影、`--focus`、`--danger` / `--danger-ink`。按钮、表单和通用状态复用这些变量；textarea 继承系统 UI 字体。暗色危险按钮使用深色文字，错误提示使用适合暗背景的前景色。
- 原生控件与共用 Button/Input/Textarea 保留键盘行为。焦点环不依赖鼠标 hover；目录行使用内侧焦点环，避免被目录裁切。新增加载图标遵循减少动态效果设置。
- `ViewState` 提供加载、空、错误三个状态；加载为 `status` / `aria-busy`，错误为 `alert`，重试由业务页面提供。状态不创建计时器或轮询。
- 书橱首次读取与失败独立呈现，重试重新执行初始化；加载时禁止新建/导入/打开。搜索失败在搜索对话框内显示并可重试，避免错误被误呈现为空结果。扩展列表区分读取中、失败、空列表，丢弃离开页面后的迟到结果。缺失图片保留错误占位并提供重新读取。
- 收藏/最近/回收站空态与懒加载编辑器、阅读器、功能页使用共用状态。备份、导入、任务中心等已有业务进度/错误展示继续保留。
- 本组不新增常驻产品模态层；主入口中的搜索、创建、导入、任务、恢复、迁移、白板均按打开条件挂载，重型功能保持 lazy import。设计样张对话框也只在打开时创建，关闭即卸载。此处是相关入口核对，不是对全仓库所有浮层的无障碍认证。

## 可运行设计样张

AI 样张包含上下文范围、引用、变更前后对照与接受/拒绝/撤销位置。按钮禁用并明确标注尚无可用页面；不连接模型，不声称实现提案 UI。真实主编辑、PDF、导入、备份与扩展页使用应用截图，不以样张代替。

样张入口为 `apps/desktop/design.html`，组件为 `src/design-preview.tsx`；与主入口无 import 关系，仅开发模式渲染，默认 Vite 生产构建不包含此页面。

## 重现步骤与证据边界

环境：macOS arm64，Node 24.22.0，项目锁定 Electron 41.9.1、Playwright 1.55.1；浏览器截图使用本机 Google Chrome。临时数据由脚本建立和清理，不操作日常知识库。

先完成构建/桌面测试，再启动 Vite 做浏览器测试。`build:backend --clean` 会暂时移除 workspace 包的 dist；不要在此时并行运行依赖 Vite 的测试。

```sh
pnpm run test:document
pnpm run test:ui
pnpm exec vite --host 127.0.0.1
# 在另一终端，指定本机浏览器路径（或使用已安装的 Playwright Chromium）
ANYNOTE_BROWSER='/Applications/Google Chrome.app/Contents/MacOS/Google Chrome' pnpm run test:bookshelf
```

## 截图评审口径

窗口固定为 1280×800、1440×900、1920×1080，分别检查亮/暗两种主题。工作区含深目录、中文标题和混合扩展；备份、PDF、扩展、设置、导入按真实页面截图。宽度断言防止根页面横向溢出，键盘断言检查可见焦点与对话框关闭/焦点恢复。

长标题在目录/标签中截断，正文保留可编辑的完整值；深目录缩进受控并保留层级标记。缺失资源和未知扩展不清空正文。审图中发现目录焦点外缘被裁切，已改为内侧环；暗主题危险按钮前景与 textarea 字体也统一到语义 token。逐组检查 83 张截图后，修正了设计样张对话框缺少表单容器背景的问题，并增加不透明背景断言；最后重跑样张矩阵、复核浅深主题原图。

本机截图与自动化不等于跨平台人工视觉签收。真实读屏、中文输入法、200% 系统缩放、系统文件/目录对话框及人工体验交给 [V012/V013](../TODO.md#v012)。云端可用性、最终签名发行包、独立设备恢复不在本组证据内。
