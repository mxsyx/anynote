# Rust 三平台设备验收（RM32）

2026-11-10。用户确认本轮仅使用当前 Mac，其他平台和真人操作留待后续。RM32 是实机验收任务；本轮交付可复用批次入口、Mac 早期证据及后续操作清单，RM32.1–.3 均保持未完成。任务状态见 [TODO](TODO.md#rm32)。

## 批次入口

Python 3.11+、仓库锁定 Rust 工具链及该平台编译依赖须已安装。复用 [RM31 驱动](RUST-NATIVE-REGRESSION.md) 的进程管理、超时、退出码和非空测试结果解析，不另建 GPUI 输入或业务断言。运行前准备本机 pin 对应的 Pdfium：

```sh
# 首次安装，目标目录必须不存在；已有安装可直接使用
python3 scripts/install-pdfium.py --output "$PWD/tmp/pdfium"
export ANYNOTE_PDFIUM_DIR="$PWD/tmp/pdfium"
python3 scripts/test-rust-device-batch.py
python3 scripts/rust-device-batch.py --device mac-arm64-lab --native --strict
```

Windows PowerShell 使用 `$env:ANYNOTE_PDFIUM_DIR = (Resolve-Path tmp/pdfium).Path`，并改用对应设备标签。Linux 须记录发行版、GPU/Vulkan 驱动和 X11/XWayland 会话；不以 Xvfb 作为物理显示证据。脚本在 Windows/Linux 的实际运行仍未验证，目标设备缺依赖或平台分支失败时保留原始错误，不以本机结果推断通过。

`--native` 在本机真实窗口中运行本地系统 WebView 100 次循环，可能占用窗口焦点；同设备按批次串行。默认只运行自动化检查，不打开真人验收流程。命令只使用仓库合成数据/模块 fixture；不读登录 Keychain、不访问真实云、不传入日常库。

产物在新建的 `tmp/rm32/<UTC时间>-<pid>/`：

- `report.json` 保存设备标签、OS/架构、工具链、锁文件/二进制/Pdfium SHA-256、逐阶段命令、结果、耗时和测试名称。Mac 另记录硬件、显示及测试目录所在卷。其他平台的硬件、显示、卷信息须补入设备报告。
- `source.json` 对全部跟踪及未忽略的新文件逐一计算摘要，保留提交和 dirty 状态。结束时再次核对，源码改变则该批次失败；文档更新发生在批次完成后，不伪造同一候选源码。
- 平台/SQLite/写入、配置 fixture、备份/迁移及编辑/白板/PDF/视频原型分别运行。任何阶段失败都不掩盖后续阶段；测试集合为空、子进程崩溃、非零退出及超时不会通过。
- Pdfium 必须匹配当前主机平台 pin 的动态库字节；WebView 必须有本轮新报告，requested/completed 都为 100 且 failure 为 null。命令退出 0 不能代替探针证据。

`selected_checks` 仅表示选中的自动检查。`acceptance` 始终为 `incomplete`，真人、其他平台、功能副本及最终包字段不会由自动化设为通过。检查失败退出 1；检查通过但使用 `--strict` 时退出 2；不加 strict 的退出 0 也不是 RM32 放行。终验仍应以候选包实际运行闭包为准，不能用此处重新编译的 debug 程序替代。

### 原生窗口观察

使用同摘要二进制创建临时未签名 `AnynoteRM32.app`，通过 `LSEnvironment` 将状态绑定到 `tmp/rm32/manual-mac/state`。这是便于桌面工具定位的调试包装，不是 RM36/37 安装包。实际打开空书橱，通过系统“工作区 → 新建笔记本…”菜单、AX 文本设值和 Return 创建 `RM32 Mac 隔离验收`，Escape 后 AX 树出现书橱条目。Cmd+Q 后工具报告 App quit；随后只读检查隔离 SQLite 的 `notebook_meta`，名称一致。

限制：AX 按钮 click 多次未触发，按路径绑定时出现 `noWindowsAvailable`，改用 bundle ID 后系统菜单可用；截图仍停留在初始空书橱，而 AX 树已更新，无法据此认定画面重绘/指针点击正常。首次连接工具耗时约 208 秒，不能当作应用启动耗时。没有完成实际正文编辑→关闭→重开、原生文件选择器、多屏移动或读屏。记录为**部分观察**，这些异常仍待真人/独立窗口驱动区分工具与产品问题。

已知未闭合项继续有效：[RM31](RUST-NATIVE-REGRESSION.md) 的 PDF 快速取消重开 SIGTRAP、跨语言移动回执失败、100 KiB debug 输入 draw 超预算，本轮未重测或修复；普通 PDF 用例通过不覆盖取消循环。RM14 完整接管/回退及 RM19 系统退出保存屏障仍未完成。
