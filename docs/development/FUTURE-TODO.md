# Anynote 远期扩展

本文件单独维护尚未纳入当前交付范围的新增能力和可选优化，不参与 [当前 TODO](TODO.md) 的 P0–P3 排期。按保存与交付增强、性能优化、内容与智能能力、平台扩展排列；具体启动顺序取决于需求与前置契约。

与当前清单共享 F 编号。确认实施后将对应条目移入当前清单、保留编号并指定优先级，不在两处重复维护。完成后移除，不复用编号。

## 归类依据

- 现有编辑、PDF 批注、白板、备份/恢复的功能缺口与安全问题必须留在当前清单；低排期的跨设备验证也不属于远期功能。
- 浏览器采集已有开发版本，剩余实现、GUI 与商店打包验收已移入 [F013](TODO.md#f013)。
- Linux 发布者签名属于当前交付 [F019](TODO.md#f019)；自动更新尚需首发决策，单独列为 F032。若首发要求自动更新，须先转入当前范围并完成实现和实机验证。
- 崩溃草稿、免捕获与 checkpoint 优化改变当前保守语义或新增恢复能力，保留在远期；AI、OCR、同步、加密、托管等须先定义范围和契约。
- 本表不授权实施、部署或付费调用。最终发行时须记录新增范围是否延期及依据，不能将已承诺的既有业务移到此处绕过验收。
