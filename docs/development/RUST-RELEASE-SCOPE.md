## F 任务对应的固定验收范围

本表保存证据身份及迁移范围映射，不记录完成状态。完成项从当前/远期清单移除后，最终候选仍需对应证据；两个清单只是剩余工作状态源。新增或调整发行范围须同步本表、清单和检查器测试。

`required` 为必需验收；`deferable` 仅允许负责人明确延期并附候选绑定的决策证据；`orchestration` 为最终汇总流程，不把流程自身的未完成复选框作为循环前置，但仍需证据和人工复核。P3 设备验收仍为 required。RM 列沿用固定迁移范围标识，多个 F 任务共同决定该范围是否仍有开放前置。

F020 保留既有大规模费用实验的延期边界；F031–F045 仅代表尚未确认的新增能力。远期项转入首发范围时须改为 required。既有浏览器采集 F013 不可延期。证据模板须与本表及检查器的范围一致；范围变化后重新生成，不能套用不同含义的编号结果。
