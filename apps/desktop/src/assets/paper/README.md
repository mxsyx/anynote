# Paper textures

Generated with the built-in image_gen tool. Each original PNG is 1024 × 1536 (2:3 portrait).
These textures are tinted by the active theme in CSS, scaled to the paper width without stretching, and repeated vertically for long notes. Plain paper remains the default. Dark themes use a stronger tint to avoid a bright paper surface.
